# V3 — Windshield wildfire route check

Built with the built-in ImageGen editor from `artwork.png`.

## Product story

A traveler rechecks one mountain-road segment before departure. One localized wildfire is visible in the landscape; sparse wind vectors carry smoke toward one orange-affected segment of the planned white route.

## Required visual logic

- Preserve the windshield, road-trip setting and photographic Sierra-like landscape.
- Keep one white route mapped onto the visible road.
- Use one short safety-orange segment where conditions affect the route.
- Show one credible, localized forest fire with smoke in the middle distance.
- Use 4–5 thin white wind vectors pointing from the fire toward the affected route.
- No snow field, dotted precipitation, detour loop, alternate route, Plan B, final recommendation, UI text, gradient, logo or watermark.

The generated raster intentionally contains no labels. Product explanation remains editable HTML on the comparison page.
