# V5 — Route Profile Forecast

Reference: `Small Things Don’t Stay Small.jfif`

Use case: productivity-visual  
Asset type: portrait 4:5 portfolio decision-system concept backdrop

Create a route-profile field-guide visual for OpenSeason. Show a long California journey as a tactile elevation cross-section from coast through foothills to a Sierra pass, grounded by real photographed terrain. Above and below the profile, use precise scientific marks for wind intensity, heat exposure, precipitation, fire risk and road access. At the highest-risk segment, the route visibly forks to a lower-elevation nearby alternative. It must read instantly as one decision story, not a collection of metric cards.

Use the reference only for its field-tested authority, strong layering and documentary texture. Use graphite, fog blue, alpine green, off-white and one warning orange. No readable text, logos, repeated cards, glass, glow, spherical 3D objects, unrelated abstract imagery, rainbow palette or watermark.
